# Business Systems Design & Analysis: a hybrid method for the AI era

Self-contained interactive reference guide. Open `index.html` directly or deploy the folder as-is to GitHub Pages (no build step).

## Contents
- `index.html` — the guide (research, animated process spine, solution-type chooser, architecture map, glossary / playbook / runbook / frameworks drawer)
- `favicon.svg`, `favicon.ico`, `favicon-16.png`, `favicon-32.png` — browser icons
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `site.webmanifest` — mobile / PWA icons

## Notes
- Fonts (IBM Plex Sans / Mono) load from Google Fonts with system fallbacks; everything else is inline.
- Light/dark theme follows the system by default; the header toggle overrides and persists in localStorage.
- Brand tokens: Prussian Blue #003153, Flag Red #C8102E, Signal Teal #12A5A0.
